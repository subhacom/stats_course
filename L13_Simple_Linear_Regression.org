* Introduction: regression analysis
** Regression analysis
Often we want to understand the relationship between a dependent variable and one or more *continuous* independent variables

\bigskip

- How does the amount of fat in food affect blood cholesterol?
- How does the number of spines in CA3 pyramidal cells in the mouse hippocampus change with age of the animal?
- In general, how does $Y$ (dependent variable) relate to $X$ (independent variable), where $X$ is continuous
- The objective is to (1) find a pattern in the relationship (describing $Y$ as a function of $X$ ), and (2) predict the value of $Y$ for a given value of $X$ .
* Simple linear regression
** Simple linear regression
There are several types of regression analysis depending on the nature of the variables: we will cover simple linear regression, multiple linear regression, and logistic regression.

\bigskip

Simple Linear Regression: The dependent variable $Y$ is continuous and depends on only one continuous independent variable $X$.


We try to fit a straight line through the data points plotted on an X-Y graph

** Simple Linear Regression
The equation of a straight line in 2 dimensions:

#+begin_export latex
\begin{equation*}
y = mx + c
\end{equation*}
#+end_export

- $y$ denotes the ordinate
- $x$ denotes the abscissa
- $c$ is the intercept, the point where the line intersects with the $Y$ -axis, or the height of the line at $x=0$
  - it may not always be interpretable, for example, if we are trying to fit $\hat{\text{weight}} = m\, \text{height} + c$, then weight of a person with height 0 does not make any sense
- $m$ is the slope, $m=\tan{\theta}$ where $\theta$ is the angle subtended by the line on the X-axis

** Simple Linear Regression
The straight line is the underlying model for simple linear regression (with $\alpha \equiv c$ and $\beta \equiv m$): $Y = \alpha + \beta x + e$ where $e$ represents random error.

\bigskip

We can only /estimate/ $\alpha$ and $\beta$ from the data. Using $A$ as estimator of $\alpha$ and $B$ as estimator of $\beta$, we want to estimate each value of the response variable $\hat{Y_{i}} = A + B x_{i}$ while minimizing the error in estimation $\epsilon_{i}$.

\bigskip

#+begin_export latex
\begin{equation*}
\epsilon_{i} \equiv Y_{i} - \hat{Y_{i}} = Y_{i} - (A + B x_{i})
\end{equation*}
#+end_export

How do we minimize the estimation error?

* Method of Least Squares

** Method of Least Squares

$\epsilon_{i} = Y_{i} - A - B x_{i}$ where $A$ and $B$ are /estimators/ of $\alpha$ and $\beta$

We want to find $A$ and $B$ that minimize the sum of squares of the error term $\sum_{i=1}^{n} \epsilon_{i}^{2}$

\bigskip

These are called /least square estimators/
** Method of Least Squares

#+begin_export latex
{\small
\begin{gather*}
\text{Let}\qquad\qquad\\
\begin{aligned}[c]
S_{xY} &= \sum_{i=1}^{n}(x_{i} - \bar{x})(Y_{i} - \bar{Y})\\
S_{xx} &= \sum_{i=1}^{n}(x_{i} - \bar{x})^{2}
\end{aligned}
\qquad\text{then it can be shown that}\qquad\qquad\\
\begin{aligned}[c]
B &= \frac{S_{xY}}{S_{xx}}\\
A &= \bar{Y} - B \bar{x}
\end{aligned}
\end{gather*}
}
#+end_export

** Linear regression with Python: LinregressResult
Some components of the result are

1. ~slope~: slope of the regression line estimated from the data ( $B$ ). For each unit increse in $x$, $Y$ increases by $\beta$ units.
2. ~intercept~: Y-intercept of the regression line estimated from the data ( $A$ )
3. ~rvalue~: the Pearson correlation coefficient (more about it later)
4. ~pvalue~: p-value for the hypothesis $H_{0}: \textit{the slope is 0}$.
   We skipped the ~"alternative"~ parameter - which defaults to ~"two-sided"~. You could pass

   ~"less"~ for $H_{1}: \textit{slope is less than 0}$ or

   ~"greater"~ for $H_{1}: \textit{slope is greater than 0}$
5. ~stderr~: standard error of the estimated slope

* Standardization
** The slope of the regression line depends on the units
Suppose you are plotting height of plants against age
- What happens if you record the height in $mm$, $cm$, or $m$, while recording age in $days$?
- What happens if you record the height in $m$, while recording age in $hours$, $days$, $weeks$, $months$ or $years$?
** Standardization soves this unit dependence
Subtract the mean and divide by the standard deviation
* Residuals
** Error random variable and residuals
Our linear regression model is $Y = \alpha + \beta x + e$
- $\alpha$ and $\beta$ are unknown parameters estimated from data as $A$ and $B$

*** Assumptions

- $e$ is the error random variable: $e \sim \mathcal{N}(0, \sigma^{2})$ - the variance of $e$ is independent of the value of $x$
- Response variables $Y_{1}, Y_{2}, \cdots, Y_{n}$ are independent (they depend only on $x$, not other $Y$ s)
*** Bottom                                                        :B_onlyenv:
:PROPERTIES:
:BEAMER_env: onlyenv
:END:
$\epsilon = Y_{i} - (A + B x_{i})$ are also called *residuals*. This is the difference between the data value and the fitted value.
** Importance of residuals
They are biproducts of the fitting, but are informative about the validity of your analysis.

*Residual analysis* is an important /diagnostic step/ after conducting linear regression.

Are your assumptions about the data valid?
- Linearity
- Constant variance (homoscedasticity)
- Independence
- Normality of errors

If these assumptions are violated, your inference can be misleading.

** Error random variable and residuals
For each $Y_{i}$ the standardized variable $\frac{e_{i}}{\sigma}$ should have a standard normal distribution.

\bigskip

Therefore, $\frac{\sum_{i=1}^{n}(Y_{i} - (\alpha + \beta x_{i}))^{2}}{\sigma^{2}}$ is chi-squared distributed with $n$ dof.

\bigskip

We lose 2 degrees of freedom in estimating $\alpha$ and $\beta$ with $A$ and $B$. Thus,

#+begin_export latex
\begin{equation*}
\frac{\sum_{i=1}^{n}(Y_{i} - (A + B x_{i}))^{2}}{\sigma^{2}} \sim \chi_{n-2}^{2}
\end{equation*}
#+end_export

** Error random variable and residuals

With $\text{SS}_{R} \triangleq \sum_{i=1}^{n}(Y_{i} - (A + B x_{i}))^{2}$,

#+begin_export latex
\begin{align*}
E\left[\frac{\text{SS}_{R}}{\sigma^{2}}\right] &= n - 2\\
\implies E\left[\frac{\text{SS}_{R}}{n-2}\right] &= \sigma^{2}
\end{align*}
#+end_export
Thus $\frac{\text{SS}_{R}}{n-2}$ is the estimator of $\sigma^{2}$

\bigskip

If a data point goes more than $2\sigma$ off the regression line, you should be suspicious of it being an outlier. Outliers are points that do not /appear/ to belong with the vast majority of the other data points.

After fitting the regression line, you want to plot the standardized residuals against $x$ as a diagnostic step. There should be no trend in this plot (normally distributed around 0).

** Diagnostics with residual analysis
By looking at the residual plots you can identify problem patterns and possible fixes for your analysis. If the data is suited for linear regression analysis, then residuals should be randomly distributed around $y=0$ line without any visible pattern

** Residual analysis: Funnel/fan shaped residual plot

Funnel/fan shaped residual plot: signals heteroscedasticity, the variance of errors is not constant.

- Try log-transforming $Y$, or use /weighted least squares/

** Residual analysis: Residuals cluster into distinct groups
Residuals cluster into distinct groups: A categorical variable (not included in the model) influences $Y$
#+begin_src python :results graphics file output :file clustered_residual.png :exports results :tangle no
  fig, ax = plt.subplots(nrows=2, sharex='all')
  x = np.arange(20)
  group = x % 2 == 0
  y = x * 7 + 3 + np.random.normal(size=x.size)
  y[group] -= 8
  result = stats.linregress(x, y)
  ax[0].scatter(x[group], y[group], color='purple', label='group A')
  ax[0].scatter(x[~group], y[~group], color='green', label='group B')
  y_hat = result.intercept + result.slope * np.r_[x]
  ax[0].plot(x, y_hat, color='red')
  ax[0].legend()
  s = np.sqrt(np.sum((y - y_hat)**2)/(len(y) - 2))
  resid = (y - y_hat)/s
  ax[1].scatter(x[group], resid[group], color='purple')
  ax[1].scatter(x[~group], resid[~group], color='green')
  ax[1].set_ylabel('Standardized residual')
  fig.set_size_inches(4,4)
  fig.tight_layout()

** Outliers
- Leverage point: an outlier far away in the horizontal (x) direction from the majority of the data points. Its value can influence (have leverage over) the slope of the regression line
  - Think of the points as weights on a rod that is represented by the regression line. Far away points will produce larger torque (that's the principle of levers)
  - If it falls close to the regression line based on the most of the data, then it does not change the slope much
- Influential point: a leverage point that actually ends up changing the slope of the regression line

** Outliers
